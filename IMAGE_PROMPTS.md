## How to Replace Images

1. Generate images using prompts above (Midjourney, DALL·E, Photoshop, or real photography)  
2. Save with **exact filenames** listed above into `public/images/...`  
3. Refresh the site — no code changes needed  
4. For CMS-managed images, upload via **Admin → Products / Gallery / Pages**
